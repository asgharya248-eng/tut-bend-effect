Tut Bend
Effect

A bend & whip VFX built entirely with Geometry Nodes, packaged as a one-click Blender addon. The node tree ships untouched — every node, value and link byte-identical to the source file.

What you get

🧬 Real GN tree

Full 174-node setup (root + nested group) embedded as an asset — links never rebuilt by hand.

🎛️ Live inputs

radius, rang, var, Count, Z exposed straight on the modifier.

🧭 Sidebar panel

View3D → Sidebar → Tut Bend: add the effect or open the original node editor in one click.

📦 Self-contained

Node groups + reference path auto-append on first use. Nothing to import.

Install in 3 steps

  1. Download tut_bend_effect.zip with the button above.
  2. Edit → Preferences → Get Extensions → ⌄ → Install from Disk and pick the zip, then enable Tut Bend Effect.
  3. Select any object, open the Tut Bend sidebar tab and press Add Tut Bend Effect.
