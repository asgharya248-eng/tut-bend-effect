Tut Bend
Effect

A bend / wave VFX built entirely with Geometry Nodes, packaged as a one-click Blender addon. The node tree is shipped untouched — every node, value and link identical to the original file.

What you get

Drop the modifier on any object and drive the bend from the N-panel.

🧬

Real Geometry Nodes

The full 174-node tree (root + nested group) ships as an embedded asset — pixel-identical links, zero hand-rebuilding.

🎛️

Tweakable Inputs

radius, rang, var, Count, Z and a switchable reference path exposed straight on the modifier.

🧭

Sidebar Panel

View3D → Sidebar → Tut Bend: one button to add the effect, one to open the original node editor.

📦

Self-contained

Node groups and the Nurbs reference path are auto-appended on first use — nothing to import manually.

Install

Works in Blender 5.2 LTS (legacy addon mode) and classic install path.

  1. Download tut_bend_effect.zip with the button above.
  2. Open Edit → Preferences → Get Extensions, click ⌄ → Install from Disk and pick the zip. از منوی کشویی «Install from Disk» فایل زیپ را انتخاب کن.
  3. Select an object, open the Tut Bend tab in the sidebar and press Add Tut Bend Effect. Done.
